# LaTeX-Dictate

Speak mathematics, get correct LaTeX — fast, private by default, and correctable by voice.

This project benchmarks today's speech and language models on spoken-math → LaTeX
(using the open [Speech-to-LaTeX](https://github.com/dkorzh10/speech2latex) dataset),
builds a small on-device model for Apple Silicon, and turns it into a push-to-talk prototype.

**Status:** planning. See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for goals, scope,
research questions, phases, targets, resources and risks.
